# Managed Clean Room — Threat Model

This folder contains the threat model for the **managed clean room** offering,
authored in the [Microsoft Threat Modeling Tool (TMT)](https://learn.microsoft.com/en-us/azure/security/develop/threat-modeling-tool).

## File

- [`managed-cleanroom.tm7`](managed-cleanroom.tm7) — the TMT model (DFD +
  generated threats).

## How to open

1. **Install the Microsoft Threat Modeling Tool** (Windows only) from the
   Microsoft Learn page:
   <https://learn.microsoft.com/en-us/azure/security/develop/threat-modeling-tool>
2. **Download** `managed-cleanroom.tm7` from this folder to your local
   machine (right-click → *Save link as…* on GitHub, or `git clone` the
   repo).
3. **Double-click** the `.tm7` file, or open TMT and choose
   *File → Open Model…* and select the downloaded file.
